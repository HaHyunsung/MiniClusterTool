# MiniClusterTool

반도체 미니 클러스터 툴 제어 시스템.
가상 장비(시뮬레이터)와 상위 제어 소프트웨어를 별도 프로세스로 분리해 구현하는 학습 프로젝트다.

기술 스택: .NET 8, C#, WPF + MVVM, SQLite, TCP/IP
기간: 8~10주 (2026-08-28 시작)


## 이 저장소를 처음 보는 AI에게

작업을 시작하기 전에 docs 폴더의 문서를 순서대로 읽어야 한다.

1. docs/02_AI_협업_지침.md — 가장 먼저 읽는다. 이 프로젝트에서 AI가 해도 되는 일과 하면 안 되는 일이 정의되어 있다. 일반적인 코딩 보조와 규칙이 다르다.
2. docs/00_개발자_컨텍스트.md — 개발자의 배경, 강점, 메우려는 역량 갭.
3. docs/01_프로젝트_사양서.md — 요구사항과 설계 제약과 로드맵.
4. docs/03_진행_상황.md — 지금 어디까지 왔는지.
5. docs/04_설계_질문_답변.md — 개발자가 스스로 답해야 하는 설계 질문과 그 답변 상태.

핵심 원칙을 한 줄로 요약하면 이렇다.
이 프로젝트의 산출물은 코드가 아니라 개발자의 판단 경험이다. 코드를 대신 써주면 프로젝트가 실패한다.
