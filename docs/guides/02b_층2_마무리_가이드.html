2. 복기 — 한 스캔에서 일어나는 일

ModuleBaseTest 생성자 순서대로 만들면 스캔 등록 순서가 밸브 → 상태머신 → 모듈이 된다. 매 스캔 FakeScanCycle이 시계를 10ms 밀고 이 순서로 Scan을 부른다.

순서누가무엇을어디
1FakeValve.ScanOpening/Closing이면 경과 시간 확인. workingTime(100ms) 지나면 Opened/Closed. timeoutTime(1s) 지나면 Fault 래칭 + State=Unknown.FakeValve.cs
2OperationStateMachine.Scan상태에 맞는 실행기 Advance(hold = Pausing/Paused). 돌아온 Fault를 ??=로 래칭. 전이 상태면 "시퀀스 완료 AND Permissive"로 자동 전이. Idle⇄Running은 RunningCondition.OperationStateMachine.cs
3ModuleBase.ScanFault ??= 하위 첫 Fault ?? 상태머신 Fault. Fault가 있고 상태가 Homing/Idle/Running/Pausing/Stopping/SemiAuto면 AbortOnFault → Abort().ModuleBase.cs

SequenceRunner.Advance 한 번의 규칙 세 가지. 테스트 4개가 각각 이 규칙을 찌른다.

  • Current가 null(스텝 사이)이면 다음 스텝을 꺼내고 Action을 한 번 부른다. hold면 꺼내지 않는다. MoveNext가 false면 IsCompleted.
  • 꺼낸 스캔이든 진행 중이든 Until을 확인한다. 참이면 Current = null. 그래서 Until이 바로 참인 스텝은 Advance 한 번에 끝난다. 다음 스텝은 다음 Advance에서 꺼낸다.
  • Action이 false거나 Timeout을 넘기면 Fault를 반환하고 Current = null. 실행기는 다음 행동을 정하지 않는다.

TwinCAT 비유: Advance = 스텝 FB의 CASE 한 바퀴. Current = null이 "다음 seqNo로 넘어갈 준비가 됨". hold = 그 seqNo에서 멈춰 있는 것.

public sealed class FakeAbortable : IFaultSource, IStandStill, IAbortable
{
    public string Name { get; }
    public Fault? Fault { get; set; }
    public bool StandStill { get; set; } = true;
    public int AbortCount { get; private set; }
    public int ClearCount { get; private set; }

    public FakeAbortable(string name) => Name = name;
    public bool Abort() { AbortCount++; return true; }
    public void ClearFault() { ClearCount++; Fault = null; }
}

5. ModuleBaseTest.cs (8개, SampleModule)

생성자. 밸브를 먼저 만들어야 스캔 순서가 2절 표와 같아진다.

clock     = new FakeClock();
scanCycle = new FakeScanCycle(clock, TimeSpan.FromMilliseconds(10));
valve     = new FakeValve("V1", ValveState.Opened, TimeSpan.FromMilliseconds(100), TimeSpan.FromSeconds(1), clock, scanCycle);
mode      = new ModeSelector(OperationMode.Auto);
module    = new SampleModule("M1", valve, mode, new TransitionTimeouts(Aborting: TimeSpan.FromSeconds(1)), clock, scanCycle);

시간 계산을 매번 하지 않도록 헬퍼 두 개를 Methods 맨 위에 둔다. 스캔 수를 세는 대신 조건이 참이 될 때까지 돌린다. 실패 시 어디서 멈췄는지 메시지에 남는다.

private void ToAborted()
{
    module.Abort();
    scanCycle.RunScans(TimeSpan.FromMilliseconds(50));
    Assert.Equal(OperationState.Aborted, module.State);
}

private void ToHomed()
{
    ToAborted();
    Assert.True(module.Home());
    RunUntil(() => module.State == OperationState.Homed, TimeSpan.FromMilliseconds(500));
}

private void RunUntil(Func<bool> condition, TimeSpan max)
{
    TimeSpan elapsed = TimeSpan.Zero;
    TimeSpan scan = TimeSpan.FromMilliseconds(10);
    while (!condition() && elapsed < max)
    {
        scanCycle.RunScans(scan);
        elapsed += scan;
    }
    Assert.True(condition(), $"조건 미충족. State={module.State}, Step={module.CurrentStep?.Name}, Fault={module.Fault}");
}
